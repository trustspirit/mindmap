# LULPUP

**Line Upon Line · Precept Upon Precept** — 한 줄씩 생각을 연결하고 쌓아가는 Next.js 마인드맵 앱.

## 실행

```bash
npm install
npm run dev
```

`http://localhost:3000`에서 실행합니다. 인증 서버가 설정되지 않은 경우에는 미리보기만 제공됩니다. 로그인·회원가입 버튼은 설정 안내를 표시하며 실제 인증 요청을 보내지 않습니다.

## 구현된 기능

- 로그인 전: 샘플/기존 로컬 맵 미리보기, 검색, 휠·터치패드 핀치 확대/축소, 빈 공간 드래그, JSON 백업.
- 로그인 후: 워크스페이스 생성/전환, 워크스페이스별 여러 마인드맵 생성/선택/자동 저장.
- 이메일을 아이디로 사용하는 비밀번호 로그인, 회원가입, 비밀번호 확인, 오류/이메일 인증 안내, 로그아웃.
- 노드 추가/삭제/편집, 가지 자동 배치, 주변 가지가 공간을 내주는 드래그, 실행 취소/다시 실행.
- 제목 옆 연필 아이콘으로 수정, 저장/취소 및 Escape 지원. 상단 경로에는 편집 버튼이 없습니다.
- 사이드바 접기/펼치기 및 상태 기억, 작은 화면에서는 겹쳐 열리는 사이드바, 스크롤과 분리된 하단 계정 영역.
- 실제 데이터 기반 맵 목록/개수. Pro 홍보, 가격/업그레이드, 가상 사용자, 더미 목록, 템플릿, 빈 도움말, 미구현 공유/댓글/스타일 및 가짜 미니맵 제거.

## Supabase 연결: 실제 로그인과 DB 저장에 필요

1. Supabase 프로젝트를 준비합니다.
2. SQL Editor에서 `supabase/schema.sql` 전체를 실행합니다. 기존 `mindmaps` 테이블이 있어도 다시 실행할 수 있습니다. 기존 맵은 기본 워크스페이스로 이관하며 ID와 내용은 보존합니다.
3. `.env.example`을 `.env.local`로 복사하고 프로젝트 URL과 공개 anon/publishable 키를 설정합니다. `service_role` 키는 사용하지 않습니다.
4. Authentication에서 Email 제공자와 신규 가입을 활성화합니다. 비밀번호 최소 길이는 8자 이상을 권장합니다. 이메일 확인이 활성화되어 있으면 가입 후 이메일 인증을 거쳐 로그인합니다.
5. Site URL과 Redirect URLs에 실제 접속 주소를 등록합니다. 로컬 개발에서는 `http://localhost:3000`과 `http://127.0.0.1:3000`을 등록합니다. 운영 환경에서는 운영 도메인을 사용합니다.
6. 개발 서버를 재시작하고 로그인 → 회원가입에서 실제 계정을 만듭니다.

인증은 Supabase Auth가 처리합니다. 앱은 비밀번호를 DB나 localStorage에 저장하지 않습니다. [비밀번호 로그인](https://supabase.com/docs/reference/javascript/auth-signinwithpassword), [회원가입](https://supabase.com/docs/reference/javascript/auth-signup) API를 사용합니다.

## 저장과 권한

- `workspaces`: 워크스페이스 ID, 소유자, 이름, 생성 시각.
- `mindmaps`: 맵 ID, 소유자, 워크스페이스 ID, 제목, 노드 JSON, 수정 시각.
- 두 테이블은 RLS로 소유자만 접근하며, `(workspace_id, owner_id)` 외래 키로 다른 사용자의 워크스페이스에 맵을 저장할 수 없게 합니다.
- 생성·편집은 버튼, 단축키, 실행 함수에서 로그인 여부를 검사합니다. 인증되지 않은 DB 요청도 RLS로 거절됩니다.
- 로그인 시 계정의 맵을 불러와 해당 계정의 로컬 백업과 수정 시각 기준으로 병합합니다. 변경은 로컬에 먼저 백업하고 700ms 후 DB에 순차 저장합니다. 저장 오류를 클라우드 저장 성공으로 표시하지 않습니다.
- 계정별 로컬 백업과 로그인 전 기존 로컬 데이터는 분리됩니다. 로그인 전 데이터가 다른 계정으로 자동 업로드되지 않습니다. 이전 `mimo-map-v1` 데이터는 기본 워크스페이스로 이관됩니다. 기존 저장 키는 호환성을 위해 유지합니다.
- 계정 전환 시 편집 기록과 화면 상태를 초기화하여 다른 맵에 실행 취소가 적용되지 않게 합니다.
- 실시간 공동 편집은 구현하지 않았습니다. 여러 기기에서 같은 맵을 동시에 수정하면 최종 저장이 반영됩니다.

## 검증

```bash
node tests/library.test.cjs
node tests/layout.test.cjs
npm run build
```

테스트는 Node.js 22.18 이상에서 실행합니다. 라이브 Supabase 연결 및 실제 이메일 인증은 프로젝트 설정 후 별도 확인해야 합니다.
